# MEMORY

Короткая общая память по проекту для Codex и Claude/CloudCode.

## Как использовать
- Перед началом работы читать `AGENTS.md` или `CLAUDE.md`, затем этот файл.
- После значимых решений обновлять только факты и договорённости, без длинных пересказов.
- Если изменение касается структуры проекта или правил работы, отражать это здесь и при необходимости в `ARCHITECTURE.md`.
