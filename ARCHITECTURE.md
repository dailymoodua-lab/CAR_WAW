# ARCHITECTURE

Короткая карта проекта для быстрого входа в контекст.

## Назначение
- Маркетинговый сайт и каталог авто для импорта машин из США, Китая и Европы.
- Основной язык контента: украинский.
- Сайт работает как статический фронтенд без сборки.

## Главные страницы
- `index.html` — главная страница и основной лендинг.
- `catalog.html` — каталог аукционных авто.
- `catalog-available.html` — авто в дороге / локальные предложения.
- `car.html` — карточка конкретного автомобиля.
- `blog.html` — блог.

## Структура фронтенда
- `css/common.css` — базовые переменные и общие стили.
- `css/layout.css` — layout-уровень.
- `css/components/` — переиспользуемые UI-части.
- `css/pages/` — стили конкретных страниц.
- `js/core/` — базовая инициализация и общие утилиты.
- `js/modules/` — переиспользуемая логика вроде фильтров и i18n.
- `js/pages/` — логика конкретных страниц.

## Ключевые JS-модули
- `js/core/initApp.js` — определяет текущую страницу и запускает нужный page module.
- `js/core/data.js` — загрузка и нормализация данных.
- `js/modules/filter.js` — логика фильтрации каталога.
- `js/modules/i18n.js` — словари и переключение языка.
- `js/pages/catalog.js` — запуск каталога через JSON-данные.
- `js/pages/catalog-available.js` — логика страницы авто в дороге.
- `js/pages/car.js` — самая чувствительная часть проекта: API, VIN-роутинг, локальные машины, галерея, карточка авто.

## Данные
- `data/api/cars_catalog.json` — данные для основного каталога.
- `data/parser/cars_transit.json` — данные для машин в дороге.
- `data/cars_api.json`, `data/cars_parser.json` — legacy/вспомогательные данные из предыдущих итераций.
- `images/local/{VIN}/` — локальные изображения машин, привязанные к VIN.

## Критические зоны
- `js/pages/car.js` нельзя рефакторить без проверки сценариев API и локальных VIN.
- `catalog-available.html` и `js/pages/catalog-available.js` частично опираются на локальные изображения и transit-данные.
- В проекте ещё встречается смешение новой структуры и legacy-подхода, поэтому перед крупными правками нужно проверять, не дублируется ли логика в HTML и JS одновременно.
